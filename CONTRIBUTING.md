# Contributing

## Change policy

- Preserve the boundary between factual blockers and prose observations.
- Add new mandatory fields only when a concrete continuity failure justifies them.
- Keep scripts zero-dependency and compatible with Node.js 20+.
- Do not introduce rules intended to evade AI detectors by reducing text quality.

## Proposing a workflow change

Describe the failure case, a before/after chapter-card example, the expected author benefit, and any new cognitive or maintenance cost. A rule with no falsifiable failure case should remain a suggestion, not a gate.
