# Agent Novel Skill v11.0 — 三型分流写作框架

> 通用 AI Agent 万能小说创作技能。一个想法 → 4问 → 自动生成全项目 → 写到完结。
> 三型分流：A型情绪章 · B型动作章 · C型功能章——每型配最小流程。
> 概率陷阱认知：最可能的续写 = 最无聊的续写（NarrativeLoom CHI 2026）。

支持 Claude Code / Cursor / Windsurf / 任意 Agent。

---

## 这是什么

Agent Novel Skill 是一份通用 AI Agent skill 定义文件。放到任意 Agent 的 skill/rule 目录下，输入"开始新小说项目"，skill 自动引导 Bootstrap 流程——4个问题 → 自动生成全部项目文件。然后说"写第1章"，v11.0 三型分流框架自动执行。

**v11.0 核心变革**：
- **三型分流**：不再一刀切8步。A型情绪章(6步) / B型动作章(5步) / C型功能章(3步)——每章先判断类型，走对应的最小流程
- **唯一画面测试提到第0步**：写前回答"读者合上眼会看到哪张画面？"，说不出来不写
- **概率陷阱认知**：AI 的"最可能续写" = 创意上"最无聊的选择"——写完后主动替换至少1处可预判走向
- **事件冷却矩阵**：6种事件类型各有冷却期，防止连续同类型写作造成疲劳
- **反向刹车**：非终局章节禁止解决核心冲突，每章必须新增≥1个未解决问题
- **自创公式检测**：不仅防AI腔，还防自己创造的公式（打火机/沉默/倒扣）
- **Anti-AI探测层**：发布前检测段落等长/套话密度/公式化转场/无错别字等平台级AI指纹
- **3+1熔断**：每3章有1章完全免检，双角色自审（读者+编辑两个身份读同一章）

## v11.0 核心升级

### 三型分流

| 章型 | 标记 | 适用场景 | 流程长度 |
|------|------|---------|---------|
| 情绪章 | 🎭 A型 | 角色内心变化、情感状态、群像独处 | 6步 |
| 动作章 | ⚔️ B型 | 事件推进、战斗、决定、道德选择 | 5步 |
| 功能章 | 🏗️ C型 | 世界构建、谈判、交易、过渡 | 3步 |

**关键规则**：禁止跨型套用。A型不查B型的检查项，B型不查C型的检查项。

### A型流程（6步）

```
A1. 事件冷却检查（30秒）→ 前2章是否同类型？
A2. 唯一画面测试 → 读者合上眼会看到什么？（说不出来→不写）
A3. 写前合同（3项承诺）
A4. 文件加载（只读需要的，不读技法文件）
A5. 写（不查技法表，信任自己）
A6. A型核验（3项：合同兑现/反向刹车/自创公式）
```

**最佳实践**：Ch.46「第一夜·房间」——热水澡场景是A型的标杆。唯一画面是"热水从头顶灌下来，肩膀缩了一下"。写之前没有查任何技法表。

### B型流程（5步）

```
B1. 事件冷却检查
B2. 唯一画面测试（95%在最后一个场景）
B3. 节奏地图（代替核心卡片：起点→前奏→核心冲突→回落→余震）
B4. 写前合同
B5. 写（允许查1次技法表）
B6. B型核验（3项：节奏兑现/慢镜头位置/标题正文一致）
```

**最佳实践**：Ch.21「不犹豫」——但标题与正文立场打架是教训。核验第3项专门防这个。

### C型流程（3步）

```
C1. 世界逻辑检查（3个问题：合理吗/有角色自己的时刻吗/信息够密吗）
C2. 写（规则最少，不查技法表，节奏要和前后章有区别）
C3. C型核验（3项：角色时刻/信息包裹/日常诡异）
```

**最佳实践**：Ch.78「东河镇」——老人的豆子剥得和末世前一样，这种日常的诡异就是C型的核心价值。

### 全局核验（每章必做）

- **Story Contract 核验**：写前3项承诺，≥2项PASS→过
- **反向刹车**：非终局章禁止解决核心冲突
- **叙事指纹检查**：补情绪标签+闲笔+道德模糊（基于StoryScope DeepMind研究）
- **5道防幻觉门禁**：人名/位置/物品/时间/数字一致性
- **自创公式检测**：打火机/沉默/倒扣——检查最近5章的重复率
- **Anti-AI探测**：仅发布前运行（段落等长/套话密度/公式化转场）

### 3+1熔断机制

每写 **3章**，第 **4章** 完全不按流程走。不判断章型、不核验、不QC。唯一质控：出声读一遍，问自己"哪里不满意？"

然后用两个身份再读一遍：
- 普通读者 → "哪里让我想跳过去？"
- 编辑 → "哪里衔接断了？"

两个身份都指出同一个问题→必须改。

## 7条硬性规则

### 1. 抽象情绪词 0 容忍
感到、觉得、知道、认为、明白 — 禁止出现在叙述中。

### 2. "不是X是Y"句式 ≤ 2 次/章
偶尔用一次有冲击力（"不是丧尸。是人。"）。用多了就是作者在说教。

### 3. 同一角色连续说话 ≤ 3 句
超过 3 句，插入动作/环境/沉默。防止对话变成"漂浮的台词"。

### 4. 段落 ≤ 250 字
250 字 ≈ 手机屏 10 行。超过这个长度，读者开始跳读。

### 5. 同一句式不连续复用
"他做了A。他做了B。他做了C。"——这不是风格，是模板 bug。

### 6. 不写角色解释他人心理状态
没有人能读心。角色当然也不能。让角色用观察和猜测替代"知道"。

### 7. 核-心驱动
不写没有"核"的场景——核=角色在这一场的内心变化（从X到Y）。找不到核→不写这个场景。禁止用"沉默+动作细节"万能公式处理所有情感场景。

> 各类型的调整建议见 `references/writing-rules.md`（建议，非强制。最终裁决权在作者。）

## 禁用词表

- 抽象情绪：感到、觉得、知道、认为、明白
- AI腔：仿佛、似乎、在...中
- 高疲劳词：不禁、忽然、竟然、宛如、猛地（每3000字≤1次）
- 各类型特有禁用词见 `references/genre-guide.md`

## 安装

```bash
git clone https://github.com/RTY798/agent-novel.git
cd agent-novel
bash install.sh
```

`install.sh` 做了三件事：
1. 把 `SKILL.md` 复制到 Agent skill 目录（默认 `~/.claude/skills/agent-novel/`）
2. 把 `references/`（15个渐进披露文件，含 v11-upgrade.md）复制到 skill 目录
3. 把 `templates/`（2个Bootstrap模板）复制到 skill 目录

不需要 pip install。不需要 npm install。不需要 Docker。零运行时依赖。

## 使用

### Bootstrap：创建新项目

```
开始新小说项目
```

Skill 自动引导 4 个问题 → 自动生成完整项目文件 → "写第1章" 或 "完善设定"。

### Write：续写章节

输入 `写第X章` 或 `写下一章`。v11.0 三型分流自动执行：
1. 章型判断（A/B/C）
2. 事件冷却检查
3. 唯一画面测试
4. Story Contract
5. 按型加载文件
6. 按型写
7. 按型核验 + 全局核验
8. 追踪文件更新

### 诊断

输入 `诊断小说` 或 `检查健康度` → 加载 9 项人工检查清单。

## 设计原则

1. **知识库 + 建议，而非自动调节的规则引擎**。最终裁决权留给作者。
2. **最小改动拿最大收益**。不建维护地狱。
3. **每一处自动化都有明确的人和工具分工**。AI 负责写，QC 脚本负责检查，你负责裁决。
4. **规则服务于文字，不是反过来**。如果一条规则让文字更生硬——无视它。
5. **每3章至少1章不按流程走**。流程保证下限，破格推高上限。

## 连贯性检查

**每5章**：每2章至少推进一次主线？无连续2章以上剧情停滞？

**每10章**：每个主角都有高光时刻？无主角连续10章被边缘化？手法审计均衡？
